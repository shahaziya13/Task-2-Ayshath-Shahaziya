# 🌊 FLOODGUARD AI

## AI-Based Flood Risk Classification System

FLOODGUARD AI is a machine-learning based classification system that analyzes environmental conditions and classifies flood risk into three categories:

- 🟢 Low Risk
- 🟠 Moderate Risk
- 🔴 High Risk

The project demonstrates the basic workflow of supervised machine learning, including dataset creation, data preprocessing, model training, testing, prediction, and deployment through a Streamlit web application.

---

## 🎯 Project Objective

The objective of FLOODGUARD AI is to build a basic AI classification model that can analyze environmental factors and classify the corresponding flood-risk category.

This project was developed as part of the **DecodeLabs Artificial Intelligence Internship – Project 2: Data Classification Using AI**.

---

## ✨ Features

- 🌧️ Rainfall-based risk analysis
- 🌊 River-level analysis
- 💧 Soil-moisture analysis
- ☁️ Humidity analysis
- 🌡️ Temperature input
- 💨 Wind-speed input
- 🌧️ Previous rainfall consideration
- ⛰️ Elevation consideration
- 🚰 Drainage-capacity consideration
- 🤖 Random Forest classification
- 📊 Prediction confidence
- 📈 Classification probabilities
- 🔎 Feature-importance analysis
- 🖥️ Interactive Streamlit interface
- 💻 Command-line prediction script
